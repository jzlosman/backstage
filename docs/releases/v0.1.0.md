# Backstage v0.1.0

This is the first public preview of Backstage for macOS.

## Find planning work

Approve a local folder and Backstage will find planning work across the Git projects below it. The default view shows recognized OpenSpec changes and common plan files. **All Markdown** lets you reach other `.md` files when you need them.

## See where you left off

OpenSpec changes have overview, task, and source views. Task progress comes from the source checkboxes. Warnings stay visible when a file is missing or malformed.

## Resume in another agent

Copy an exact file path or a continuation prompt. Paste it into a new agent session and continue from the source instead of rebuilding the context from memory.

## Keep repositories read-only

Backstage does not edit scanned repositories. It stores its index and settings in app-owned folders. Pi summaries run only after an explicit request.

## Download

Download `Backstage_0.1.0_universal.dmg` for macOS 13 or newer. The app supports Apple Silicon and Intel Macs. The release is signed with a Developer ID certificate and notarized by Apple.

Use `SHA256SUMS.txt` to verify the downloaded files.

## Public preview limits

- macOS only
- Deterministic support for the OpenSpec layout listed in the [v1 support guide](../v1-support.md)
- A small set of common planning filenames in the default view
- Optional Pi summaries require the audited setup listed in the support guide
- No chat-history restoration or live agent-session management
