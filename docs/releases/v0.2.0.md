# Backstage v0.2.0

Backstage v0.2.0 makes planning work easier to manage and scan across many repositories.

## Manage roots and planning patterns

Open **Settings** to add or remove approved roots. Removing a root revokes access and clears Backstage-owned cached data without changing the repository.

Planning-file discovery now uses an editable list of regular expressions. You can remove the built-in patterns, add your own project-relative Markdown patterns, or restore missing defaults.

## See OpenSpec lifecycle at a glance

OpenSpec changes now have explicit **Active**, **Done**, and **Archived** status. Current and archived changes use the same Overview, Tasks, and Source reader. The ledger also shows open and completed task counts when `tasks.md` is available.

## Find recent work faster

The work ledger sorts records by exact modification time and groups them under **Today**, **Past 7 days**, **Older**, and **Date unavailable**. Dates, lifecycle status, and task counts are now primary row metadata.

## Safer workspace updates

This release strengthens scan and cache coordination around settings changes. Delayed scans and summary jobs cannot restore content after its final approved root is removed, and overlapping roots retain content that remains reachable.

Backstage still treats repositories as read-only input. Settings, indexes, and generated summaries remain in app-owned storage.

## Download

Download `Backstage_0.2.0_universal.dmg` for macOS 13 or newer. The app supports Apple Silicon and Intel Macs. The release is signed with a Developer ID certificate and notarized by Apple.

Use `SHA256SUMS.txt` to verify the downloaded files.

## Upgrading

Install v0.2.0 over the existing app. Backstage migrates its app-owned settings and index database on launch; approved repositories remain untouched.

## Public preview limits

- macOS only
- Deterministic support for the OpenSpec layout listed in the [v1 support guide](../v1-support.md)
- Planning patterns apply globally across approved roots
- **All Markdown** files do not receive OpenSpec lifecycle, task progress, or Pi actions
- Optional Pi summaries require the audited setup listed in the support guide
- No chat-history restoration or live agent-session management
